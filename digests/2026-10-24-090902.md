**Guillermo Rauch (CEO, Vercel)**

Vercel CEO Guillermo Rauch raised a technical alarm: agents can play "Ouija" on shared-host VMs. Timing attacks on shared virtual machines — where one agent detects another by measuring CPU cache noise — have been known since 2015 but remain unsolved. With AI agents, the threat becomes real at scale. The only complete fix would require each agent to run on dedicated hardware, which carries major cost implications. Rauch noted that Vercel Sandbox has deployed every practical mitigation available, complemented by always-on monitoring and red-teaming.
https://x.com/rauchg/status/2113759533801877920

Vercel CEO Guillermo Rauch 发出了一个技术警告：agent 可以在共享虚拟机上玩"占卜板游戏"。共享 VM 上的时序攻击——一个 agent 通过测量 CPU 缓存噪声来侦测另一个 agent——自 2015 年便已为人所知，却至今无根本解法。随着 AI agent 大规模部署，这一威胁变得切实可行。唯一的彻底解决方案是让每个 agent 运行在专属硬件上，但这将带来巨大的成本压力。Rauch 表示，Vercel Sandbox 已部署了所有可行的缓解措施，并辅以全天候监控和红队测试。

**No Priors — "Democratizing Security for the Agentic Web with Cloudflare CTO Dane Knecht"**

**The Takeaway:** AI is simultaneously causing a security crisis and providing the only realistic path to solving it — and the people discovering the most dangerous vulnerabilities today aren't nation-states, they're high school kids with agents and bug bounty accounts.

Cloudflare CTO Dane Knecht describes a fundamental shift in the threat landscape: what used to be a Log4j-scale security event once a year is now happening weekly. He calls it a "vuln apocalypse" — and the driver is AI. The same models being used to build software are being pointed at existing software to find exploits, by everyone from nation-state actors to teenagers running capture-the-flag-style agent competitions. Knecht noted that OpenAI recently found the seeds for NIST cryptographic curves from 2000 — exploits that would have taken expert humans years to uncover are now tractable for agents.

But Knecht pushes back on the doomsday framing. He believes human adaptability and industry collaboration will win out. More counterintuitively, he argues that *current* AI is actually making software *less* secure in the short term: "AI, at least the early AI is very verbose. It likes to create complexity." Reducing attack surface requires simplification, and today's models trend toward adding code, not removing it.

Cloudflare's internal response includes building CloudflareOS — an internal AI platform used more by go-to-market and G&A teams than engineers — and a "Codex" document encoding engineering best practices that agents must follow. Their token governance philosophy is notably hands-off: employees aren't graded on token usage but get gentle email nudges if they exceed certain thresholds.

Perhaps the most provocative strategy: Cloudflare hired 1,000 interns into a 5,000-person company specifically to inject AI-native intuition throughout the organization. Managers with AI-native interns adopted AI faster — so they doubled down. On the new economic model for the agentic web, Knecht is bullish on micropayments and new payment rails that agents will force into existence: "I think agents will actually push that forward and actually we will see a world where there is a new economic model for content creators."
https://www.youtube.com/@NoPriorsPodcast

**核心观点：** AI 同时在制造安全危机，也是解决这场危机的唯一现实路径——而如今发现最危险漏洞的，不是国家级行为者，而是拿着 agent 和 bug bounty 账号的高中生。

Cloudflare CTO Dane Knecht 描述了威胁格局的根本性转变：过去一年才出现一次 Log4j 级别的安全事件，现在每周都在上演。他将其称为"漏洞末日"（vuln apocalypse），驱动力正是 AI。用来构建软件的同款模型，正被用来攻击现有软件寻找漏洞，参与者从国家级行为者到青少年无所不有——后者在进行类似 capture-the-flag 的 agent 竞赛，并从 bug bounty 中获得丰厚回报。Knecht 提到，OpenAI 近期找到了 2000 年发布的 NIST 密码学曲线的随机种子——这类本需顶级专家耗费数年的漏洞挖掘，如今对 agent 来说已唾手可得。

但 Knecht 并不认同末日叙事。他相信人类的适应能力和行业协作终将占据上风。更反直觉的是，他认为*当前*的 AI 在短期内实际上让软件*更不安全*："AI，至少是早期的 AI，非常冗长，喜欢制造复杂性。"缩小攻击面需要的是简化，而今天的模型倾向于增加代码，而非减少。

Cloudflare 的内部应对方案包括：构建 CloudflareOS（一个被市场和职能团队使用远多于工程团队的内部 AI 平台），以及编写一份名为"Codex"的文档，规定 agent 必须遵循的工程最佳实践。他们的 token 治理哲学出人意料地宽松：员工不会因为 token 用量被考核，但超出特定阈值会收到温和的邮件提醒。

最大胆的策略或许是：Cloudflare 在 5000 人规模的公司里招募了 1000 名实习生，专门用来向全组织注入 AI 原生直觉。拥有 AI 原生实习生的管理者本身也更快采用了 AI——于是他们决定加倍押注。关于 agent 时代互联网的新经济模式，Knecht 对微支付和新支付轨道充满信心："我认为 agent 将真正推动这一切，我们将看到一个内容创作者拥有全新商业模式的世界。"
