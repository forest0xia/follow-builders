**Claude Blog — "Claude in Chrome is generally available"**

Claude in Chrome is now live on all paid Claude plans — and for the first time, Claude can take autonomous browser actions without requiring approval for each step. A safety classifier validates every action against your original request before it runs. Claude can read pages, click links, fill out forms, and navigate sites using your existing logins — useful for internal dashboards, legacy systems, and vendor portals that lack native Claude integrations.

The post details significant progress on prompt injection defenses. With probes, a safety classifier, and model training against a growing library of attack patterns, Anthropic reports 0% attack success against Claude Sonnet 5 and Opus 5 (probes + classifier). Fable 5 saw 0.3%, all in low-severity scenarios. Compare that to Opus 4.5 at 16.7% even with probes — a dramatic improvement. To start: install from the Chrome Web Store. Enterprise admins can restrict to approved domains.
https://claude.com/blog/claude-in-chrome-generally-available

**Claude Blog —「Claude in Chrome 正式全面开放」**

Claude in Chrome 现已在所有付费 Claude 计划中上线，Claude 首次能够在浏览器中自主执行操作，无需对每个步骤逐一审批。每个操作在执行前都会由 safety classifier 对照你的原始请求进行核查。Claude 可以读取页面、点击链接、填写表单，并以你现有账号登录并在网站间导航——对没有原生 Claude 集成的内部仪表盘、旧系统和第三方供应商门户尤为实用。

这篇文章详细介绍了 prompt injection 防御方面取得的重大进展。通过 probe 扫描、safety classifier 和针对不断扩充攻击模式库的模型训练，Anthropic 报告对 Claude Sonnet 5 和 Opus 5（启用 probe + classifier）的攻击成功率为 0%。Fable 5 的攻击成功率为 0.3%，且均属低危场景。相比之下，Opus 4.5 即使启用 probe 攻击成功率仍高达 16.7%——进步可谓显著。开始使用：从 Chrome 网上应用店安装即可。企业管理员可将访问范围限制在已批准的域名内。
https://claude.com/blog/claude-in-chrome-generally-available
