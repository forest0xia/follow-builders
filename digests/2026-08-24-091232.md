**Claude Blog: Building intelligent apps for Apple platforms with Claude in the Foundation Models framework**

Anthropic has released a new Swift package that brings Claude into Apple's Foundation Models framework — the same framework developers use today to tap into Apple's on-device models. With just a few lines of Swift code, developers can now hand off to Claude when a task requires multi-step reasoning, code generation, web search, or code execution, while keeping the on-device model for fast local tasks like summarization or extraction. Because Apple's framework returns typed Swift values via `@Generable` annotations, developers arrive at the Claude API call with clean, structured inputs. The integration streams Claude's response back into the same SwiftUI view. Works on iOS 27, iPadOS 27, macOS 27, visionOS 27, and watchOS 27.
https://claude.com/blog/claude-for-foundation-models

Anthropic 发布了一个新的 Swift 包，让 Claude 进入 Apple 的 Foundation Models framework——同一个开发者用来调用 Apple 端侧模型的框架。只需几行 Swift 代码，开发者便可在需要多步推理、代码生成、网页搜索或代码执行时将任务交给 Claude，同时保留端侧模型处理摘要、提取等快速本地任务。由于 Apple 的框架通过 `@Generable` 注解返回类型化的 Swift 值，开发者到达 Claude API 调用时已有干净、结构化的输入。该集成支持将 Claude 的回复以流式方式返回到同一 SwiftUI 视图中。兼容 iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watchOS 27。
