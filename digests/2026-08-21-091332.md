### Anthropic Engineering

**An update on recent Claude Code quality reports**
[https://www.anthropic.com/engineering/april-23-postmortem](https://www.anthropic.com/engineering/april-23-postmortem)

Anthropic published a detailed postmortem on the Claude Code quality degradation that users reported over the past month. Three separate, unrelated changes compounded into what looked like broad, inconsistent regression — affecting Claude Code, the Claude Agent SDK, and Claude Cowork (the API was unaffected).

The three issues: (1) A March 4 change dropped default reasoning effort from `high` to `medium` to reduce UI-freezing latency; after user backlash, it was reverted on April 7 — all models now default to `xhigh` for Opus 4.7 and `high` for others. (2) A March 26 caching optimization meant to clear old thinking blocks once after idle sessions had a bug that cleared them on *every* subsequent turn, making Claude increasingly forgetful and causing cache misses that drained usage limits faster. Fixed April 10. (3) An April 16 system prompt addition — "keep text between tool calls to ≤25 words" — hurt coding quality and was reverted April 20 after ablations showed a 3% drop.

As of April 23, Anthropic reset usage limits for all subscribers. Going forward: broader eval suites per system prompt change, tighter soak periods, gradual rollouts, and expanded Code Review context (Opus 4.7 caught the bug when given full repo context; Opus 4.6 did not).

Anthropic 发布了一份详细的事后复盘，针对过去一个月用户反映的 Claude Code 质量下滑问题。三项相互独立的变更叠加，造成了表面上看来范围广泛、规律不一的退步——分别影响了 Claude Code、Claude Agent SDK 和 Claude Cowork（API 层未受影响）。

三个问题：(1) 3 月 4 日将默认推理强度从 `high` 降至 `medium` 以减少界面卡顿，用户反馈强烈后于 4 月 7 日回滚——现在所有模型默认使用 `xhigh`（Opus 4.7）或 `high`（其他模型）。(2) 3 月 26 日的一次缓存优化原本设计为在空闲会话后只清除一次旧的思考块，但存在 bug，导致后续每轮都会清除，使 Claude 越来越健忘，并触发持续缓存未命中，加速消耗使用额度，于 4 月 10 日修复。(3) 4 月 16 日在系统 prompt 中加入了"工具调用间的文字不超过 25 词"的限制，消融实验显示带来 3% 的质量下滑，于 4 月 20 日回滚。

自 4 月 23 日起，Anthropic 为所有订阅用户重置了使用额度。后续改进：每次系统 prompt 变更都将运行更广泛的评估套件、更严格的浸泡期和灰度发布，以及扩展 Code Review 的代码库上下文范围（Opus 4.7 在获得完整仓库上下文后成功定位了 bug，而 Opus 4.6 未能做到）。

**Scaling Managed Agents: Decoupling the brain from the hands**
[https://www.anthropic.com/engineering/managed-agents](https://www.anthropic.com/engineering/managed-agents)

Anthropic Engineering detailed the architectural evolution behind Managed Agents — their hosted long-horizon agent service. The core insight is framed as a classic systems design problem: the original single-container design (session + harness + sandbox all colocated) was a "pet" — a fragile, hand-tended server that was hard to debug and couldn't scale.

The solution was to decouple the "brain" (Claude + harness) from the "hands" (sandboxes and tools) and the "session" (durable event log). Each became an independent interface: `execute(name, input) → string` for tools, `wake(sessionId)` and `getSession(id)` for harness recovery, and `getEvents()` for interrogating the session log outside Claude's context window.

The payoffs were concrete: p50 time-to-first-token dropped ~60%, p95 dropped over 90% (brain no longer waits for container provisioning). Security improved because credentials never enter the sandbox where untrusted code runs — OAuth tokens live in an external vault, and git tokens are embedded in the remote at initialization. And the architecture now naturally supports many brains reaching into many hands — enabling customer VPC deployments without network peering.

Anthropic Engineering 详述了 Managed Agents 背后的架构演进——这是他们托管的长时程 agent 服务。核心问题被类比为一个经典系统设计难题：最初将 session、harness 和 sandbox 全部塞进单一容器的方案，是一个脆弱的"宠物"服务器——难以调试，无法扩展。

解决方案是将"大脑"（Claude + harness）与"双手"（sandbox 和工具）以及"会话"（持久化事件日志）彻底解耦。三者各自成为独立接口：工具通过 `execute(name, input) → string` 调用，harness 通过 `wake(sessionId)` 和 `getSession(id)` 实现故障恢复，`getEvents()` 则支持在 Claude 上下文窗口之外查询会话日志。

效果立竿见影：p50 首 token 时延下降约 60%，p95 下降超 90%（大脑不再需要等待容器启动）。安全性也随之提升——凭证不再进入运行不可信代码的 sandbox，OAuth token 存储于外部 vault，git token 在初始化时嵌入 remote。同时，该架构天然支持多个大脑连接多双手，无需网络对等即可实现客户 VPC 部署。

### Claude Blog

**New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels**
[https://claude.com/blog/claude-managed-agents-updates](https://claude.com/blog/claude-managed-agents-updates)
*(Published May 19, 2026)*

Two significant additions to Claude Managed Agents: self-hosted sandboxes (public beta) and MCP tunnels (research preview, access by request).

Self-hosted sandboxes let enterprises run Claude agent tool execution on infrastructure they control — or with managed providers like Cloudflare, Daytona, Modal, or Vercel. Code, sensitive files, packages, services, and data stay within the enterprise perimeter under existing security and runtime controls. The orchestration layer (context management, error recovery, agent loop) stays on Anthropic's infrastructure; only tool execution moves into the customer-controlled environment.

MCP tunnels allow Managed Agents to reach private Model Context Protocol servers — internal databases, APIs, knowledge bases, ticketing systems — without exposing them to the public internet. A lightweight gateway makes a single outbound connection with no inbound firewall rules needed, encrypted end-to-end. MCP tunnels are also supported in the Messages API.

Early adopters include: Amplitude (using Cloudflare for on-brand design agents), Clay (Daytona-powered GTM engineering agent Sculptor), and Rogo (Vercel Sandbox for a finance analyst agent handling proprietary data).

Claude Managed Agents 推出两项重要更新：自托管 sandbox（公开 beta）和 MCP tunnel（研究预览，需申请访问）。

自托管 sandbox 允许企业在自己控制的基础设施上运行 Claude agent 的工具执行——也可选用 Cloudflare、Daytona、Modal 或 Vercel 等托管提供商。代码、敏感文件、包、服务和数据全部留在企业安全边界内，沿用现有的安全与运行时控制策略。编排层（上下文管理、错误恢复、agent 循环）仍运行在 Anthropic 的基础设施上，只有工具执行部分迁移到客户自控环境。

MCP tunnel 允许 Managed Agents 连接私有 Model Context Protocol 服务器——包括内部数据库、API、知识库、工单系统——无需将其暴露在公网。一个轻量级网关只需建立一条出站连接，无需开放任何入站防火墙规则，全程端对端加密。MCP tunnel 同时支持 Messages API。

早期采用者包括：Amplitude（使用 Cloudflare 构建品牌设计 agent）、Clay（在 Daytona 上运行 GTM 工程 agent Sculptor），以及 Rogo（在 Vercel Sandbox 上构建处理专有数据的金融分析 agent）。

### No Priors — "From Restoring Sight to Reimagining the Brain, with Max Hodak"
[https://www.youtube.com/watch?v=7HXqMepjvy8](https://www.youtube.com/watch?v=7HXqMepjvy8)
*(Published August 20, 2026)*

**The Takeaway:** The brain is a computer — and treating it as one is unlocking medical breakthroughs faster than decades of drug discovery ever could.

Max Hodak is the founder and CEO of Science (formerly of Neuralink), a medical device company that in July 2026 received European regulatory approval to commercially sell Prima — a retinal prosthesis that restores a form of vision to people who have gone completely blind. The chip implants under the retina, patients wear laser-projector glasses, and the system bypasses dead rods and cones to stimulate the retina directly. Clinical trial patients were reading books and filling in crossword puzzles. First sales are happening in the coming weeks.

Hodak's core provocation: "The brain very literally, very clearly, plainly is a computer." He argues this framing — controversial in academic neuroscience — is what makes brain-computer interfaces tractable in a way that drug development is not. Drug discovery involves turning over cards with uncertain answers that may take a decade to arrive. BCI follows engineering logic: you can see a clear path to make the product better and better. "If I put electrodes in M1, you will probably be using a computer in an hour."

On the AI-neuroscience convergence: Hodak is a believer in the "platonic representation hypothesis" — the observation that the mathematical structures inside large AI models closely resemble the representations found in neuroscience. He uses this practically at Science: alignments between animal neural recordings and AI model internal representations give him confidence that AI is not hitting a wall but "grabbing onto some true underlying data manifold."

His long-term vision is substrate independence — the ability to swap, replace, and eventually decouple the brain from its biological support systems. Not brain-keyboard. Not silent speech. The real prize is getting vision, hearing, balance, and motor signals in and out of the brain, at which point — as he puts it — "you're halfway to the matrix."

**The Takeaway（核心结论）：** 大脑是一台计算机——以计算机的方式对待它，正在以远超数十年药物研发的速度解锁医学突破。

Max Hodak 是 Science 公司（前 Neuralink 成员）的创始人兼 CEO。2026 年 7 月，该公司获得了欧洲监管机构的商业销售许可，旗下产品 Prima——一款视网膜假体——可为完全失明的患者恢复某种形式的视觉。芯片植入视网膜下方，患者佩戴内置激光投影仪的眼镜，系统绕过死亡的视杆细胞和视锥细胞，直接刺激视网膜。临床试验患者已经能够阅读书籍、填写填字游戏。首批商业销售将在未来数周内启动。
