### Training Data — Parallel's Parag Agrawal: Building a New Web for AI Agents

**The Takeaway:** Former Twitter CEO Parag Agrawal argues that human click data is fundamentally a bug for AI search — and that the rise of agents creates both the problem (web infrastructure built for humans won't scale) and the solution (agent feedback can replace the human signals search has always depended on).

Agrawal is back on the founder arc as CEO of Parallel Web Systems, a company building search and web infrastructure specifically designed for AI agents. The pitch: just as humans use browsers, search engines, and clicking to access the web, agents will do the same — at a scale he estimates could be 1000x larger than human web usage. That kind of volume requires reinventing both the technology layer (crawling, indexing, ranking) and the accompanying business models.

What makes Parallel's bet interesting is its timing. When Agrawal started the company three years ago, two problems made it hard to build a challenger to Google-scale search: (1) generating high-quality feedback for ranking without human ratings or click data, and (2) the sheer infrastructure cost of a full web crawl. His thesis: agents solve problem #1 entirely. Instead of inferring relevance from where humans click, you can use agent feedback directly — agents doing tasks generate their own signal about whether a search result was actually useful. "Human click data is a bug," he says — a proxy that was always imperfect, and that agents don't need.

The conversation also covers how Agrawal is deliberately unlearning lessons from running a scaled, post-product-market-fit company like Twitter (where feedback loops came from hundreds of millions of users and 30+ minutes of daily engagement) versus building a pre-PMF company betting on a customer that doesn't fully exist yet: AI agents as a distinct category of web user.

Agrawal's vision is that the web itself will need to be rebuilt — not just search engines, but how information is structured, indexed, and monetized — for a world where the primary consumer is an agent, not a person.

**一句话结论：** 前 Twitter CEO Parag Agrawal 认为，人类点击数据从根本上是 AI 搜索的一个 bug——而 agent 的兴起既带来了挑战（为人类构建的网络基础设施无法扩展），也带来了解决方案（agent 反馈可以替代搜索一直以来依赖的人类信号）。

Agrawal 以 Parallel Web Systems CEO 的身份重返创业，该公司专门为 AI agent 构建搜索和 Web 基础设施。核心逻辑是：就像人类用浏览器、搜索引擎和点击行为访问网络，agent 也将做同样的事情——但规模可能是人类 Web 使用量的 1000 倍。这种体量需要从根本上重新发明技术层（爬取、索引、排序）和配套的商业模式。

Parallel 的赌注之所以有趣，在于时机。三年前 Agrawal 创业时，有两大障碍使得挑战谷歌级别搜索极为困难：①在没有人类评分或点击数据的情况下生成高质量的排序反馈；②全量爬取 Web 的巨大基础设施成本。他的核心论点：agent 彻底解决了第一个问题。与其从人类点击行为推断相关性，不如直接使用 agent 反馈——agent 在执行任务时会自然产生关于搜索结果是否真正有用的信号。他说："人类点击数据是一个 bug"——它始终是一个不完美的代理指标，而 agent 根本不需要它。

对话还涵盖了 Agrawal 如何有意识地"去学习"管理 Twitter 这样成熟规模化公司的经验——在那里，反馈来自数亿用户和每日 30 分钟以上的使用时长——转而去建立一家押注于尚未完全成形的客户群体（AI agent 作为 Web 的独立用户类别）的前 PMF 公司。

Agrawal 的愿景是：整个 Web 都需要被重建——不仅仅是搜索引擎，还包括信息的结构化方式、索引方式和变现方式——以适应主要消费者是 agent 而非人类的世界。
